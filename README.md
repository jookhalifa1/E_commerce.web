# E-Commerce Web API

A full-featured E-Commerce Web API built with ASP.NET Core following Clean Architecture principles. Supports Products, Categories, Orders, Cart management, Authentication, and Authorization.
## Features

- Full CRUD operations for Products, Categories, and Orders
- Shopping Cart management
- Authentication & Authorization with ASP.NET Identity & JWT Tokens
- Role-based access control (Admin, User)
- Filtering, Sorting, Searching, and Pagination for products
- Repository Pattern & Specification Pattern for scalable and maintainable queries
- Redis Caching for optimized performance
- AutoMapper for mapping entities to DTOs
- Global Exception Handling Middleware
- Swagger/OpenAPI Documentation for all endpoints
## Tech Stack

- **Backend:** ASP.NET Core, C#
- **Database:** Microsoft SQL Server, Entity Framework Core
- **Caching:** Redis
- **Architecture & Patterns:** Clean Architecture, Repository Pattern, Specification Pattern, SOLID principles
- **Tools:** Swagger/OpenAPI, AutoMapper, Git/GitHub
